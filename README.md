# BiasLens

**Agentic AI for fairness analysis in machine learning models**

Live app: [biaslens-ai-srv.streamlit.app](https://biaslens-ai-srv.streamlit.app/)

BiasLens is a fairness auditing pipeline that takes a tabular dataset, trains multiple classifiers on it, and evaluates each one across five standard fairness metrics — not just accuracy. It's built as a set of coordinated agents rather than a single script, so each stage (profiling, cleaning, model training, fairness scoring, reporting, Q&A) is independent and auditable.

## Why this exists

Most fairness toolkits (AIF360, Fairlearn) are powerful but assume you already know what Disparate Impact or Equal Opportunity Difference mean, and expect you to wire together your own pipeline. BiasLens automates the pipeline and uses an LLM layer to explain what the numbers actually mean, so the output is readable by someone without a stats background.

## What it does

1. **Upload a CSV** — the app profiles it: column types, missing values, candidate sensitive attributes.
2. **Clean the data** — median/mode imputation, categorical encoding, documented decisions.
3. **Configure the analysis** — pick a target column and a sensitive attribute (e.g. `sex`, `race`).
4. **Run bias analysis** — trains Logistic Regression, Random Forest, SVM, and XGBoost, computes fairness metrics for each, and picks the best model using a weighted score across all five metrics (not just accuracy).
5. **Read the report** — plain-language summary of what was found, generated by an LLM grounded in the actual numbers.
6. **Ask questions** — a chat interface answers follow-up questions about your specific results.

## Fairness metrics

- **Accuracy** — overall correctness
- **Disparate Impact (DI)** — ratio of positive prediction rates between groups (1.0 = parity, <0.8 = commonly flagged as biased)
- **Statistical Parity Difference (SPD)** — difference in positive outcome rates between groups
- **Equal Opportunity Difference (EOD)** — difference in true positive rates between groups
- **Average Odds Difference (AOD)** — average of TPR and FPR differences between groups
- **Theil Index** — inequality measure applied to predictions

The privileged/unprivileged split is decided automatically (majority class in the sensitive column on the test split) and reported back to the user rather than left implicit.

## Real results

Run on two public datasets, sensitive attribute excluded from training features in both cases:

**Titanic** (target: `survived`, sensitive attribute: `sex`)

| Model | Accuracy | DI | SPD | EOD | AOD |
|---|---|---|---|---|---|
| Logistic Regression | 0.657 | 1.052 | 0.014 | -0.208 | -0.138 |
| Random Forest | 0.652 | 1.534 | 0.160 | 0.011 | 0.038 |
| SVM | 0.640 | 1.770 | 0.086 | 0.078 | 0.022 |
| XGBoost | 0.596 | 1.123 | 0.043 | -0.014 | -0.043 |

**Adult Census Income** (target: `income`, sensitive attribute: `sex`)

| Model | Accuracy | DI | SPD | EOD | AOD |
|---|---|---|---|---|---|
| Logistic Regression | 0.805 | 0.335 | -0.115 | -0.144 | -0.093 |
| Random Forest | 0.859 | 0.325 | -0.174 | -0.079 | -0.074 |
| SVM | 0.800 | 0.467 | -0.028 | 0.037 | 0.018 |
| XGBoost | 0.876 | 0.323 | -0.180 | -0.106 | -0.082 |

Adult shows real, substantial bias — every model's Disparate Impact falls well below the 0.8 threshold, meaning women are predicted `>50K` income at roughly a third to half the rate of men across all four classifiers. Titanic is comparatively close to parity by comparison, with some spread depending on the metric.

## Architecture

Five agents coordinate through a shared state object rather than running as a linear script:

- **DataProfilerAgent** — column types, missing values, candidate sensitive attributes
- **DataCleaningAgent** — imputation, encoding, documented preprocessing
- **BiasDetectionAgent** — trains models, computes fairness metrics, selects best model
- **ReportGenerationAgent** — LLM-generated fairness reports at multiple detail levels
- **ConversationalAgent** — answers user questions grounded in the analysis context

```

├── agents/
│   ├── base_agent.py

├── app.py
└── requirements.txt
```

## Tech stack

- **Frontend:** Streamlit
- **ML:** scikit-learn (Logistic Regression, Random Forest, SVM), XGBoost
- **Fairness metrics:** custom implementation, no external fairness library dependency
- **LLM layer:** Groq API, for report generation and the conversational interface
- **Deployment:** Streamlit Cloud

## Design decisions worth knowing

- **Sensitive attribute excluded from training features by default.** Including it and relying on "fairness through unawareness" doesn't actually prevent proxy discrimination, so it's dropped from `X` unless explicitly opted back in.
- **ID-like feature columns are auto-detected and dropped** before encoding (near-unique columns like `Name` or `PassengerId`). Label-encoding a near-unique text column turns it into an arbitrary per-row integer that can leak identity signal and inflate fairness metrics without adding real predictive value.
- **Binary targets only in v1.** Targets with more than two classes are rejected with a clear error rather than force-fit through a median split, which would produce meaningless results on non-ordinal or multi-class data.
- **Model selection uses all five metrics**, weighted (accuracy 30%, DI 20%, SPD/EOD 15% each, AOD 10%, Theil 10%), not just accuracy and DI. Weights are hardcoded and documented in `bias_detector.py`, not tuned per dataset.
- **5-fold stratified cross-validation** reported alongside the single test-split accuracy, so results aren't presented as more stable than they are.

## Known limitations

- No active bias mitigation (reweighing, adversarial debiasing) — detection only, not correction
- No hyperparameter tuning
- Deep learning models out of scope
- Binary classification only
- SVM with `probability=True` is noticeably slower than the other three models on larger datasets (Platt scaling overhead)

## Running locally

```bash
git clone https://github.com/Sreelakshmi-rv/biaslens-ai.git
cd biaslens-ai
pip install -r requirements.txt
```

Add your Groq API key to `.streamlit/secrets.toml`:

```toml
GROQ_API_KEY = "your_key_here"
```

Then:

```bash
streamlit run app.py
```
